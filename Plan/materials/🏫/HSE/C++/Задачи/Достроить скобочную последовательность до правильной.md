## Условие 

Входной поток: последовательность скобок: (), [], {}

Не удаляя ни одного символа из входной последовательности, дополнить её символами соответствующих *закрывающих* скобок на произвольных позициях так, чтобы она стала правильной. Считаем, что может не хватать только закрывающих и что можно их правильно доставить

Использовать контейнеры нельзя, выводить на std::cout

`[({] -> [({})] или [(){}]`

## Решение

Открывающие скобки печатаем сразу
Как только нашли закрывающую:
1. Поднимаемся до парной открывающей
2. Для каждой непарной открывающей на пути доставляем закрывающую

```c++
char CorrectPars() {
	char c;
	if (!std::cin.get(c)) {
		return '';
	}

	if (c == ')' || c == ']' || c == '}') {
		return c;
	}
	std::cout << c;
	const char closing = CorrectPart();
	if (closing == [нужная закрывающая]) {
		std::cout << closing;
		return CorrectPart();
	}
	if (closing != '') {
		std::cout << [нужная закрывающая] << std::endl;
		return closing;
	}
}
```
