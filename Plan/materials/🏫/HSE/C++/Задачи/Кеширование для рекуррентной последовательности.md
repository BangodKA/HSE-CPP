Последовательность задается рекуррентной формулой, для примера:

$f(n) = f(n - 1) * 2 - f(n - 2) * 3 - f(n - 4) + 1, n > 4$

$f(n) = n, 0 <= n <= 4$

Задача: написать функцию, которая бы вычисляла f(n)

Заметим, что решение в лоб имеет экспоненциальную сложность. Нужно какое-то кэширование либо динамика. Возникает вопрос: где хранить кэш/данные, если они должны сохраняться между вызовами функции?
