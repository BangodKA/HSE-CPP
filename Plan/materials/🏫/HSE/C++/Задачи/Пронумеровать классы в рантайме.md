## Условие

Посчитать, сколько разных специализаций шаблона класса используется

```c++
GetIndex<int>() -> 0
GetIndex<double>() -> 1
GetIndex<std::string>() -> 2
GetIndex<int>() -> 0
```

## Решение

```c++
int global_index = 0;
template <typename T>

size_t GetIndex() {
  static size_t index = global_index++;
}
```
