## Условие
Можно начать с C-style, звено списка — структура Node, сам список — указатель на голову.
- Показать, что неудобно держать функции в глобальной области видимости, запихнуть в класс, спрятать определение структуры Node внутри класса List. 
- Не забыть спрятать в private указатель на следующий элемент списка, чтобы пользователь не смог случайно его сломать.
- Итераторы пока не проходили, поэтому предложим более явные методы прохода по списку: например, используя методы или свободные функции вместо перегруженных операторов. Здесь может понадобиться friend, если Iterator и Node будут разными сущностями. 
- Не забыть про деструктор, поговорить про конструктор копирования, хотя бы косвенно.
