## Условие
Написать двумерный массив фиксированного размера (указывается в конструкторе), добавить ему операторы присваивания и конструктор копирования. Не забыть обработать присваивание самому себе. В качестве эксперимента можно написать метод swap (предполагается, что move-конструкторов пока не знаем), это позволит написать присваивание через copy-and-swap, рассказать, почему этот метод имеет смысл (strong exception guarantee).

Дополнительно, можно добавить возможность итерации по массиву двойным range-based for:

```c++
for (auto row : matrix.rows()) {
    for (auto& i : row) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
}
```

Аналогично, поддержать `columns()` (подумать, как лучше организовать итератор по столбцу массива, можно ли будет переиспользовать код из итератора по строкам и т.д.). Поговорить про константность и необходимость добавления константных итераторов, показать, что код получается аналогичным с точностью до типов, и, если группа хорошо себя чувствует, предложить решение с шаблонным итератором и using’ами на него
