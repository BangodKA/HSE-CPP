# Реализация
## Структура

```cpp
int main(int argc, const char** argv) {
  try {
	  Args
	  BMP->Image
	  ApplyFilters: for filter in vec { filter->Apply }
	  Image -> BMP
  } catch (std::exception& exc) {
	  std::cout << exc.what() << std::endl;
	  return 10;
  } catch (...) {
	  std::cout << "Unexpected ... throw" << std::endl;
	  return 100;
  }
  return 0;
}
```

## Подготовка
- Args
	- Нужен отдельный класс, который распарсит аргументы из argc/argv
	- Поля: нужные в программе типы, удобные для использования
- BMP
	- Один или два класса для чтения из файла в Image и записи из Image в файл
- Image
	- Чтобы легко менять форматы изображений, не меняя основную логику программы
	- Хранение матрицы изображение удобно и эффективно сделать одномерным вектором
- Filters
	- почему в фильтрах стоит работать именно с Image, свободным от формата
	- наследование в фильтрах
	- Можно создавать с помощью карты фильтров или с помощью switch/case
	- 3 Паттерна
		- Фабрика. Для создания фильтров, если использовать карту фильтров
			- можно делать без отдельной структуры на static-методе Filter
			- можно делать с помощью отдельных функций
			- можно делать отдельное дерево наследников
		- Композит. Для создания комбинированного из других фильтра
		- Визитор. Чтобы изображение применяло к себе фильтры, а не применять каждый фильтр `image.apply(filter)  // внутри вызывает filter->apply`
# Оценка
## Начисления (по критериям из репозитория)

### Минимум (max: 3): 3
- Класс для представления цвета
- Класс для представления изображения
- BMP
- Один любой класс фильтра (например, Crop)

### Базовые фильтры (каждый max: 0.6): 3
- Grayscale
- Negative
- Sharpening
- Edge Detection
- Gaussian Blur
### Дополнительный фильтр (max: 1)
Комбинированный засчитывается до 0.5, если понятен итоговый смысл фильтра и не совсем простой
Простые фильтры засчитываются до 0.5

### Иерархия фильтров (max: 2):
За плоскую иерархию до 1. Плоская иерархия – все фильтры наследуются от базового

### Покрытие тестами (max: 1)
1 балл ставится за наличие хотя бы одного теста на метод применения каждого фильтра
