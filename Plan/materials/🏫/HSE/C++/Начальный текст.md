Всем привет!

Вся работа на курсе будет происходить через систему https://base.cpp-hse.net/
Для регистрации нужно:
1. Подключиться к Wi-Fi ВШЭ
2. Заполнить форму на сайте
	1. Код: `ami-cpp-<номер группы>-<номер подгруппы>`
	2. First Name – Имя
	3. Second Name – Фамилия
	4. Почта – Вышкинская
3. Нажать `Sign Up with Gitlab`
4. Зарегаться в Gitlab

В системе есть кнопка `My Repo` – так можно перейти в своей репозиторий
Там можно найти файл `SETUP.md` – это инструкция для настройки окружения
После прохождения инструкции нужно перейти в `task/multiplication` и выполнить шаги в `README.md` для сдачи задачи
