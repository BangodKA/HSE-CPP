    * `std::weak_ptr`
* <span style="color: #888888">Copy-on-write</span>
    * Смысл на std:shared_ptr
```c++
#include <iostream>
#include <memory>
#include <string>

int main() {
    auto a = std::make_shared<std::string>("cat");
    auto b = a;  // Скопировали shared_ptr, но не строку.

    std::cout << a.use_count() << '\n';  // 2
    std::cout << (a.get() == b.get()) << '\n';  // 1

    // Хотим изменить b, не затронув a.
    if (b.use_count() > 1) {
        b = std::make_shared<std::string>(*b);
    }
    (*b)[0] = 'b';

    std::cout << *a << '\n';  // cat
    std::cout << *b << '\n';  // bat
    std::cout << (a.get() == b.get()) << '\n';  // 0
}
```
- Исторический контекст – раньше строки были copy-on-write, но были сложности. С C++11 стандарты запрещают
