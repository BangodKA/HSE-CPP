* Git — только команды; Подробное обсуждение в Тулинге

    ```text
    git checkout main
    git pull
    git checkout -b <новая ветка>
    или
    git checkout <существующая ветка>
    ```

    Повторять, пока хочется:

    ```text
    ...
    git add .
    ...
    git commit -m "хорошее сообщение"
    ```

    Отправить изменения:

    ```text
    git push
    ```

## Настройка для Windows

- [Git for Windows](https://git-scm.com/install/windows)
- Git Bash – все команды там (там работают необходимые Unix-команды

```bash
ssh-keygen -t rsa
```

- `C:\Users\YourUsername\.ssh\id_rsa`
- `C:\Users\YourUsername\.ssh\id_rsa.pub`

- Скопировать в буфер обмена
```bash
clip.exe < ~/.ssh/id_rsa.pub
```

Настроить ssh-конфиг:

```bash
mkdir -p ~/.ssh
cat >> ~/.ssh/config <<'EOF'

Host hse
  User git
  HostName gitlab.cpp-hse.net
  IdentityFile ~/.ssh/id_rsa
EOF
```

Дальше все по обычной инструкции, заменяя `git@gitlab.cpp-hse.net` на `hse`
