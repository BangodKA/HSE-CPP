* Паттерн — название повторяющегося проектного решения, а не обязательная конструкция в коде
* Strategy
    * Общий интерфейс фильтра
    * Разные реализации `Apply`
* Factory
    * Создание фильтра по имени и аргументам командной строки
    * Сначала показать прямой `if` / `switch`
    * Затем показать проблему расширения и вынести создание в фабрику
* Builder
    * Отдельно закрепляется в задаче `http_builder`
* Composite
    * Имеет смысл для отдельного составного фильтра
    * Не обязателен для базовой реализации проекта
* Visitor
    * Обсудить назначение double dispatch
    * Не требовать в Image Processor без отдельной задачи, которую он действительно решает
