    * <span style="color: #888888">Вывести строку с конца</span>
    * <span style="color: #888888">Пример к пунктам про терминальный ноль и вывод с конца:</span>

      ```cpp
      char str[] = "abc";
      std::cout << sizeof(str) << '\n';          // 4: три символа и '\0'
      std::cout << (str[3] == '\0') << '\n';     // 1

      std::size_t length = 0;
      while (str[length] != '\0') {
          ++length;
      }
      while (length > 0) {
          std::cout << str[--length];
      }
      std::cout << '\n';                       // cba
      ```
