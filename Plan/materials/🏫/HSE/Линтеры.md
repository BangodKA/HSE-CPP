### Установка
- Mac
	- `brew install llvm`
	- `export PATH="$(brew --prefix llvm)/bin:$PATH"`
- Linux
	- `sudo apt install clang-format clang-tidy`
- `clang-format --version`, `clang-tidy --version`

### clang-format — форматирование
- `.clang-format`
- `clang-format main.c`
- `clang-format -i main.c`
- `clang-format --dry-run --Werror main.c`
- `clang-format --style=LLVM --dump-config > .clang-format`
- `BasedOnStyle`, `IndentWidth`, `ColumnLimit`

### clang-tidy — статический анализ
- `.clang-tidy`
- `clang-tidy main.c -- -std=c17`
- `clang-tidy main.cpp -- -std=c++20`
- `clang-tidy --list-checks`
- `clang-tidy main.cpp --checks='-*,clang-analyzer-*,bugprone-*,performance-*,readability-*' -- -std=c++20`
- `clang-tidy main.cpp --fix -- -std=c++20`

### Проект и CMake
- `cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON`
- `build/compile_commands.json`
- `clang-tidy -p build main.cpp`
- Стандарт языка, `-I`, `-D` из команды сборки

### Настройка проверок
- `.clang-tidy`: `Checks`, `CheckOptions`, `WarningsAsErrors`
- `clang-tidy --dump-config`
- `NOLINT(check-name)`, `NOLINTNEXTLINE(check-name)`
