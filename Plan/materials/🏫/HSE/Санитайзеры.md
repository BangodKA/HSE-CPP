### Установка
- Mac
	- `brew install llvm`
	- macOS: `export PATH="$(brew --prefix llvm)/bin:$PATH"`
- Linux
	- `sudo apt install clang llvm`

### Сборка
- `-g`, `-O1`, `-fno-omit-frame-pointer`
- `clang -std=c17 -g -O1 -fno-omit-frame-pointer -fsanitize=address,undefined main.c -o main`
- C++: `clang++`, `-std=c++20`
- `-fsanitize=...` при компиляции и линковке

### AddressSanitizer — память
- `-fsanitize=address`
- Выход за границы массива
- Use-after-free, use-after-scope, double-free
- Стек ошибки, место выделения и освобождения памяти

### UndefinedBehaviorSanitizer — UB
- `-fsanitize=undefined`
- Переполнение знакового целого, деление на ноль, некорректный сдвиг
- Разыменование `NULL`, невыровненный доступ
- `-fno-sanitize-recover=undefined`
- `UBSAN_OPTIONS=print_stacktrace=1 ./main`

### LeakSanitizer — утечки
- Linux: включён вместе с ASan
- `ASAN_OPTIONS=detect_leaks=1 ./main`
- Отдельно: `clang -std=c17 -g -fsanitize=leak main.c -o main`

### ThreadSanitizer — гонки данных
- `clang++ -std=c++20 -g -O1 -fsanitize=thread -pthread main.cpp -o main`
- Конфликтующие обращения, стеки потоков
- Отдельная сборка: TSan несовместим с ASan и LSan

### Границы проверок
- Только выполненные ветки программы
- Неинициализированные значения — MemorySanitizer, не ASan
- Беззнаковое переполнение — не UB; `-fsanitize=unsigned-integer-overflow`
